# Raw FASTQ staging area

This directory is reserved for locally supplied full-input Dorado FASTQ files.
In a public copy of the repository, it is normal for this directory to be empty
or to contain only helper notes.

The full study input contains 128,431 Dorado SUP reads and was deposited under
NCBI BioProject [PRJNA1561677](https://www.ncbi.nlm.nih.gov/bioproject/PRJNA1561677).
Place the study FASTQ here (for example, as `Samlst_SUP.fastq.gz`) before running
Option A in the [repository README](../README.md).

For lightweight verification, use the public test assets under `demo/` and
`fixtures/`.
