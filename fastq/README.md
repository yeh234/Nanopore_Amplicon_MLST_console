# Raw FASTQ staging area

This directory is reserved for locally supplied full-input Dorado FASTQ files.
In a public copy of the repository, it is normal for this directory to be empty
or to contain only helper notes.

If you want to run the root workflow from raw reads, place the full FASTQ here
before running Option A from the repository root `README.md`.

The full study FASTQ is not committed to the public GitHub repository. For
lightweight verification, use the public test assets under `demo/` and
`fixtures/`.
