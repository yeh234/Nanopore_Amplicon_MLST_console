# Figure5 subsampling

This release produces the Figure 5 analysis for `sample4` using outputs from the
main repository workflow.

It supports two standard workflows:

- a full rerun from the main-workflow demultiplexed `sample4` FASTQ through subsampling, assembly, polishing, genotyping, and plotting
- a direct replot from an existing full `r100` genotype table

## Key Files

- `run_figure5_sample4_5to60_r100.sh`
  Full pipeline runner for `sample4`, covering `5-60` reads with `100` replicates per read depth.
- `replot_figure5_from_full_r100.sh`
  Replots the final `5-60` Figure 5 panel from an existing full `r100` genotype table.
- `code/MAF_revised.R`
  Plotting script used by the release workflows.
- `code/rebuild_figure5_batch.sh`
  Batch runner used by the full pipeline.
- `code/rebuild_figure5_genotype.sh`
  Genotyping helper used by the batch runner.

## Quick Start

Full rerun from the demultiplexed `sample4` FASTQ generated by the main workflow:

```bash
bash run_figure5_sample4_5to60_r100.sh
```

Direct replot from existing full `r100` results:

```bash
bash replot_figure5_from_full_r100.sh
```

## Inputs and Outputs

Default input for the full pipeline:

- `../output/01_demultiplex/merged_by_sample/sample4.fastq.gz`

Default assembly consensus used by the standalone genotype helper:

- `../output/02_assembly/sample4/sample4_assembly_polish_consensus.fasta`

Default MLST allele/profile directory for the full pipeline:

- `../db`

Default outputs:

- `output/Figure5_sup_5to60_full_r100.pdf`
- `output/Figure5_sup_5to60_full_r100.png`
- `output/Figure5_sup_5to60_full_r100_summary.tsv`
- `output/sample4_patch_genotype_result_full_r100.txt`
- `output/sample4_patch_manifest_full_r100.tsv`

Intermediate files from the full pipeline are written to:

- `output/work`

The full pipeline uses the repository-root `../db` by default. You can override
that location with `MLST_DB_DIR`.

Replotting from an existing genotype table does not require any MLST database
files.

## Replot Workflow

The replot workflow requires only:

- `output/sample4_patch_genotype_result_full_r100.txt`

The following file is also provided for bookkeeping:

- `output/sample4_patch_manifest_full_r100.tsv`

Note:

- `MAF_revised.R` uses the genotype table only.
- The manifest file in `output/` was reconstructed from the archived genotype table because a single archived `sample4_patch_manifest_full_r100.tsv` was not present in `outputold/`.

Optional overrides for the replot script:

```bash
INPUT_FILE=output/sample4_patch_genotype_result_full_r100.txt \
OUTPUT_PREFIX=output/Figure5_sup_5to60_full_r100 \
SUMMARY_FILE=output/Figure5_sup_5to60_full_r100_summary.tsv \
bash replot_figure5_from_full_r100.sh
```

Equivalent direct `Rscript` invocation:

```bash
INPUT_FILE=output/sample4_patch_genotype_result_full_r100.txt \
OUTPUT_PREFIX=output/Figure5_sup_5to60_full_r100 \
SUMMARY_FILE=output/Figure5_sup_5to60_full_r100_summary.tsv \
LOW_READ_ZOOM_MIN=5 \
LOW_READ_ZOOM_MAX=60 \
Y_AXIS_MIN=0 \
Y_AXIS_MAX=1.02 \
LABEL_READ_MIN=5 \
LABEL_READ_MAX=15 \
FORCE_LABEL_READS=35,45,60 \
GUIDE_READ=35 \
GUIDE_READ_LABEL="Approximate transition into high-correctness range" \
GUIDE_READ_SECONDARY=45 \
GUIDE_READ_SECONDARY_LABEL="All loci >=99% correctness" \
Rscript code/MAF_revised.R
```

## Full Pipeline Overrides

Example override pattern for the full pipeline:

```bash
OUT_DIR=output \
INPUT_FASTQ=../output/01_demultiplex/merged_by_sample/sample4.fastq.gz \
MLST_DB_DIR=../db \
FLYE_THREADS=1 \
MEDAKA_THREADS=1 \
bash run_figure5_sample4_5to60_r100.sh
```

The full pipeline expects `seqkit`, `flye`, `medaka_consensus`, `minimap2`,
and `samtools` to be available through `PATH`. You can also point each tool
explicitly with the environment variables `SEQKIT`, `FLYE`,
`MEDAKA_CONSENSUS`, `MINIMAP2`, and `SAMTOOLS`.

## Plot Defaults

- read range: `5-60`
- replicates per read depth: `100`
- y-axis range: `0` to `1.02`
- guide lines: `35` and `45` reads
- guide labels:
  - `Approximate transition into high-correctness range`
  - `All loci >=99% correctness`
- percentage labels shown only for:
  - `5-15`
  - `35`
  - `45`
  - `60`
